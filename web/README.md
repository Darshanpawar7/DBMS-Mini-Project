# ScholarMesh — web app

Next.js 16 front end and API for ScholarMesh. Setup, commands and demo accounts are in the
[project README](../README.md).

```bash
npm run dev         # http://localhost:3000
npm test            # unit + database tests
npm run test:e2e    # Playwright browser tests
npm run db:setup    # rebuild the database from ../db/*.sql
npm run db:embed    # compute missing embeddings
```
